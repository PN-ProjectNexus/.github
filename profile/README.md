# About Project Nexus

Project Nexus est un projet centré autour du développement avancé pour FiveM.

Création de scripts optimisés, systèmes complexes, expériences immersives et mappings personnalisés pour serveurs RP, Freeroam, Racing ou projets uniques.

L’objectif est de produire des ressources modernes, performantes et propres.
